# Automated Casino (FireRed) for mGBA

This script automates playing the casino in Pokémon FireRed using the mGBA emulator. It is based on [this YouTube video](https://www.youtube.com/watch?v=QevklyPMweE).

## How to use

1. Download the `casino.lua` script.
2. In mGBA, click **Tools** → **Scripting**.
3. Click **Load script** and select the downloaded `casino.lua` file.
4. Start Pokémon FireRed in mGBA.
5. Stand in front of a slot machine in the casino.
6. Press the controller button mapped to **B** to start the script.
7. Let it run.

For the fastest results, you can enable fast-forward and set the speed to **10×** before starting the script.

## How to stop

Return to the script overview in mGBA's scripting window and select **Reset** from the drop-down menu to stop the script.
